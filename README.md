
# Kajun Cowboy Recipe Box

Week 5 Day 5 - Recipe Box Project

This website lets users find recipes and add new dishes using the DummyJSON API.

## Features

- Find a recipe using its ID
- Display recipe name, cuisine, and preparation time
- Add a new dish using a POST request
- Show loading and sending messages
- Handle empty inputs and errors
- Display results safely using textContent

## Endpoints

GET https://dummyjson.com/recipes/{id}
Gets one recipe by its ID.

POST https://dummyjson.com/recipes/add
Adds a dish using a practice API. Dishes are not permanently saved.
